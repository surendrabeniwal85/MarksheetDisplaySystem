# Marksheet Display System

This is a Java-based desktop application that allows users to enter student details and subject marks, generate a marksheet, and export it as a PDF.

I built this project to practise Java programming concepts while creating something useful and interactive.

## Features

- Enter student and institution details.
- Add subject names and marks.
- Display the generated marksheet in a desktop GUI.
- Export the marksheet as a PDF.
- Automatically switch between marksheets after 20 seconds of inactivity.
- Use Java concepts such as inheritance, generics, sealed classes, text blocks, switch expressions, and multithreading.

## Technologies Used

- Java 25
- Java Swing
- Maven
- Apache PDFBox

## How to Run

1. Install JDK 25 and Maven.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

   ```bash
   mvn clean compile
   mvn exec:java
   ```
